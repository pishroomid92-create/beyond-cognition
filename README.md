# فراتر از شناخت | Beyond Cognition

هسته پژوهشی برای ثبت و پیگیری نظام‌مند پرسش‌ها، مراحل تحلیل، شواهد و گزارش اجرای مدل‌ها.

## وضعیت نسخه

نسخه رابط: **0.3.1**

این نسخه برای راه‌اندازی اولیه مغز پژوهشی طراحی شده است. ثبت اجرای مدل در حال حاضر ثبت گزارش اجرای انجام‌شده است؛ اتصال خودکار به API ارائه‌دهندگان مدل هنوز پیاده‌سازی نشده است.

## امکانات فعلی

- ایجاد جلسه پژوهشی با عنوان و پرسش مرکزی
- مدیریت وضعیت جلسه: فعال، متوقف، تکمیل‌شده
- ثبت مراحل پژوهش با نقش مشخص و برچسب وضعیت معرفتی
- اتصال شاهد به هر مرحله دلخواه، همراه با نوع، منبع و ارزیابی اعتبار
- ثبت و مشاهده گزارش اجراهای مدل/عامل
- مشاهده رکوردهای قدیمی جدول `research_records` بدون حذف یا تبدیل اجباری
- دریافت نسخه پشتیبان JSON از داده‌های پژوهشی

## راه‌اندازی در Streamlit Community Cloud

در بخش **App settings → Secrets** این دو مقدار باید در دسترس برنامه باشند:

```toml
SUPABASE_URL = "https://YOUR_PROJECT.supabase.co"
SUPABASE_KEY = "YOUR_SERVER_SIDE_KEY"
```

کلید دارای دسترسی ممتاز فقط باید در Secrets سمت سرور باقی بماند؛ هرگز آن را در کد، مخزن GitHub، مرورگر یا پیام عمومی قرار ندهید.

## ساختار پایگاه داده

- `research_records`: حافظه نسخه قدیمی
- `research_sessions`: جلسات پژوهش
- `research_steps`: مراحل هر جلسه
- `research_evidence`: شواهد متصل به مراحل
- `model_runs`: گزارش اجرای مدل‌ها

## محدودیت امنیتی مهم

در نسخه فعلی، صفحه ورود اختصاصی حذف شده است. چون برنامه Streamlit عمومی است و عملیات پایگاه داده از سمت سرور با کلید ممتاز انجام می‌شود، هر فردی که به نشانی برنامه دسترسی داشته باشد ممکن است از طریق رابط به داده‌ها دسترسی خواندن/نوشتن پیدا کند.

بنابراین تا پیش از پیاده‌سازی احراز هویت و مجوزدهی واقعی، اطلاعات محرمانه یا حساس در این برنامه وارد نکنید. فعال بودن RLS بدون policy به‌تنهایی این برنامه را ایمن نمی‌کند؛ کلید ممتاز سمت سرور از RLS عبور می‌کند. مرحله امن‌سازی باید با طراحی مالکیت داده، Supabase Auth و policyهای محدودکننده انجام شود، بدون انتشار کلید ممتاز.

## پشتیبان‌گیری

از تب «پشتیبان‌گیری» فایل JSON دریافت کنید و آن را در محل امن نگه دارید. این فایل ممکن است شامل متن پرسش‌ها، تحلیل‌ها، شواهد و پاسخ مدل‌ها باشد.
